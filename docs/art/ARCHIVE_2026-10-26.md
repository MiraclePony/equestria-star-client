安装Godot 4.6.2 .NET与.NET 8，先完成Godot资源导入和 `dotnet build`；根目录预览脚本支持 `-GodotPath` 指定自备Godot位置。本机 `.art-tools` 中的引擎没有上传。

```powershell
./验收纸艺世界V5.ps1 -GodotPath '你的Godot 4.6.2 .NET可执行文件路径'
```

```powershell
New-Item -ItemType Directory -Force artifacts | Out-Null
if (-not (Test-Path artifacts/paper-v5-before-diagnostic.json)) {
    Copy-Item tests/art/paper-v5-camera-fixture.json artifacts/paper-v5-before-diagnostic.json
}
```
