## 森林实际变化

上一版为了控制轮廓，在无尽森林多数使用普通深绿松树，只有少量专属树。这不符合用户要求，现已纠正：

- 30 个普通无尽森林格全部使用 **VEG006／007／008／009** 四种弯曲树干、青蓝宽树冠的专属模型，共 74 棵主树。每格固定 2—3 棵，位置、转角、大小由稳定种子确定。
- 普通松树继续服务于其他适合的地区，不进入这些无尽森林主树组。旧城堡、泽可拉与谐律树保留其原本专属装饰，不重复挤入主树林。
- 每格近景准备一组蘑菇与两簇 VEG104 折叶植物，组合与方向有变化。已有地标装饰和森林林缘仍保留。中心留位、候选棋子身体和实际三角面检查继续约束摆放。
- 主树和完整建筑不随缩放移动、变大或换网格。四档仅管理独立的低矮装饰、稀疏枕木和信息密度；关闭自动网格 LOD，项目阈值与运行视口均为 0。

没有重新制作或覆盖源 `.blend`，也没有重复导出。环境索引仍为 v005，60 项／306 个环境 GLB，与地标合计 421 个 GLB，源哈希检查无变化。

## 光影选择

已在同一森林镜头、1760×1000 输出中分别运行 Mobile 与 Forward+。本轮选择 **Godot Forward+ 作为桌面默认渲染器**，没有迁移到另一套游戏引擎。原 C#、地图、材质和资产管线继续使用。

使用固定暖白日光、偏蓝紫补光、短半径接触 AO、少量屏幕空间间接光；主光阴影降低不透明度并加宽固定过滤。减少漂浮感，保留树冠下的冷影与折面。缩放不改变曝光或光源方向，正常操作没有景深。

| 参数 | 当前值 |
| --- | --- |
| 日光颜色／能量 | `fff0d6`／1.12 |
| 环境补光颜色／能量 | `bbc1df`／0.32 |
| 阴影不透明度／过滤模糊 | 0.72／2.2 |
| SSAO 半径／强度 | 0.16／1.30 |
| SSIL 半径／强度 | 0.75／0.30 |

SSIL 是有限的屏幕空间间接光，不是完整全局光照；没有启用 SDFGI、反射或体积雾。官方机制参考：[Godot 渲染器](https://docs.godotengine.org/en/4.6/tutorials/rendering/renderers.html)、[环境与 SSIL](https://docs.godotengine.org/en/4.6/tutorials/3d/environment_and_post_processing.html#screen-space-indirect-lighting-ssil)、[关闭自动网格 LOD](https://docs.godotengine.org/en/4.6/classes/class_viewport.html#class-viewport-property-mesh-lod-threshold)。参数和选型为本项目实际实现及视觉判断。

同一森林区域镜头的本机渲染内存统计约 Mobile **231 MiB**、Forward+ **394 MiB**。后者成本更高，保留明确回退入口；不能将截图效果或本机 RTX 5000 Ada 的结果当成手机性能保证。
