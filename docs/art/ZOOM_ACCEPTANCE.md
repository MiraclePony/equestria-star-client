## 开始验收

在客户端根目录运行：

```powershell
./验收缩放版.ps1
```

默认打开 50 号概念构图。滚轮连续缩放，鼠标拖动棋盘；左侧可切换「总览／区域／近景／展示」，关闭「缩放细节装饰」或「环境动画」作对照。关闭细节不重建地图，也不关闭棋子与操作提示。面板顶部显示 Z 档、地面六角占屏比例和加载状态。下拉菜单 51 号可查看新到的九项天空素材。

```powershell
# B3 是此次测试格，并非所有地图的固定森林 ID
./打开美术预览.ps1 -View 50 -FocusCell B3 -DetailScale 0.23
./打开美术预览.ps1 -View 51
# 重跑导入、构建和实际渲染验收
./验收缩放版.ps1 -RunChecks
```

已构建时可加 `-SkipBuild`。依赖本机 `.art-tools` 中的 Godot 4.6.2 .NET 和 .NET SDK，不是独立发行包。截图对照页：`artifacts/zoom-review.html`；机器报告：`artifacts/zoom-acceptance.json`。`artifacts/` 被 Git 忽略。

## 实际完成的行为

采用用户提供的《环境资源与制作需求.md》《调研与缩放需求.md》及 R01—R12 标注图。此前可访问聊天与交接资料的读取边界见 [INTEGRATION.md](INTEGRATION.md)；没有把不完整的记录称为全部私人记忆。四档与参数是本项目的实现与实测结果，不代表 Paradox 的内部技术。

尺度依据是**地面六边形投影高度／有效地图视口高度**，不使用最高建筑的高度。正式 HUD 和预览检查面板的占屏区域会扣除。配置位于 `assets/art/zoom-detail.json`。

| 状态 | 标称分界 | 当前展示 |
| --- | --- | --- |
| Z0 总览 | 小于 6% | 保留地块、边界、建筑主体、主树和关键提示；隐藏低矮碎装饰与草稿枕木，双轨方向保持 |
| Z1 区域 | 6%—16% | 主体与主树不变，显示稀疏枕木；从 12% 起准备附近细节 |
| Z2 近景 | 16%—35% | 在可见范围内渐显蘑菇、矮植物、小石等安全分件；最多同时展示 12 格细节 |
| Z3 展示 | 高于 35% | 支持继续靠近和更精细的导入网格 LOD 阈值；没有伪造未交付的窗框、树根或屋檐模型 |

分界有 ±10% 滞回。例如 Z1→Z2 进入点 17.6%，退出点 14.4%；Z2→Z3 为 38.5%，退出点 31.5%。细节用约 0.30 秒稳定抖动透明过渡。主树不参与显隐或缩放，固定位置、朝向、尺寸和主轮廓；主树自动 LOD 受到保守限制。完整建筑与地面支撑保持常驻，不把它们误判为低矮装饰。

当前格、选中格、可行动格、已有 `TokenRoot` 棋子和指定有效路径由独立屏幕提示层表达。圈标与文字保持屏幕尺寸，离屏时使用边缘提示；路径必须通过已有边关系核对。装饰图层不接收鼠标事件，遮住提示的云和气球会隐藏。测试胶囊只是验收体，不是已接入服务器的真实角色。

预取覆盖视口外 15% 的边缘范围，最多两个资源加载请求同时进行。加载未完成时基础棋盘和主体继续显示；只在加载状态完成时取回资源，不用提前阻塞式取回。迟到结果不会在已离开的格子实例化。资源按路径共享，多个拥有者仍引用的资源不回收。

每帧最多实例化一个小组件，软时间预算 2 ms；冷细节保留 8 秒，实例缓存目标最多 32 格，回收最多两格／帧；冷资源预算 32 项，活跃资源受保护。**2 ms 不能中断一次已开始的实例化**，因此不是硬帧时保证。释放本控制器的节点与引用也不等于强制清空 Godot 全局缓存或 GPU 显存。

## 尚未完成的部分

1. **真实模型 LOD 与首屏流送**：没有同源对齐的 LOD0/1/2／Proxy 文件。主体常驻，使用导入网格可用的自动 LOD 和小装饰流送；初次基础地图创建仍同步。需要提供同原点、同落点、同剪影的简化版本，再测首屏、内存与切换。不要把细节隐藏称为全模型卸载。
2. **区域地貌与连续地形**：R01—R12 已作为约束记录，但皇城完整山壁平台、马哈顿港湾、骏鹰独立海岛岸线、森林弯曲通道等尚未逐区完成。外围山群、南侧湖泊和跨区水面仍为试排，不能称为正剧地理复原或无缝水系。
3. **铁路与棋子**：双轨为原纸棋盘白线的离线描线草稿，站台端口、桥隧、转角、分岔拼接未验收，未作为正式铁路加入在线地图。真实角色体积、所有路径支撑与多人站位需继续验证。
4. **近景质量与性能**：部分建筑仍比概念简化。需真正的纸折边、窗框、树根和烘焙纤维／局部 AO；主树优先三至五组大折面。重复植被、材质数量、同步初始化和峰值需优化，并测试目标手机、低端回退和发行包。当前不会靠加强滤镜补造型。
5. **玩法全流程**：当前格／可行动／已有棋子提示已接入，路径高亮提供边关系校验入口；离线胶囊与测试路径不能代替联网多人回合、移动动画或全部正式 HUD 的人工验收。
